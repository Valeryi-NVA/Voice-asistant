# Астра 1.0 — требования к полной версии

Цель: русскоязычный голосовой помощник для Android и автомобильного режима. Без обязательной подписки, платного API и root на первом этапе.

## Функциональность
- Активация «Астра» / «Привет, Астра», локальный детектор ключевой фразы, управление микрофоном с явным согласием и видимым системным уведомлением.
- Русская речь, предпочтительно женский голос, непрерывный диалог, прерывание озвучивания голосом, локальные команды без интернета.
- Телефон: исходящие звонки, повтор последнего номера, выбор контакта и SIM, подтверждение неоднозначных совпадений, ответ/отбой и громкая связь через роль телефонного приложения и разрешенные Android API.
- Яндекс Навигатор: запуск, поиск адреса, маршруты, поиск АЗС; возможности внешнего управления подлежат проверке.
- Яндекс Музыка: запуск, воспроизведение, пауза, следующий/предыдущий трек, громкость через разрешенные MediaSession API.
- Bluetooth автомобиля: маршрутизация звука, автомобильный режим, проверка при заблокированном экране и во время звонков.
- ИИ: Ollama/Astra Server на Windows 10, частный доступ через Tailscale; на телефоне локальные команды доступны без сервера. Не публиковать адреса и секреты в репозитории.
- Модульная архитектура, расширяемые команды, ручное выключение фонового режима, экономия энергии.
- Исключены SMS, Telegram, WhatsApp, доступ к переписке и управление ПК.

## Сборка и проверка
GitHub Actions: сборка APK без локального компьютера. Для выпуска необходимы успешная сборка, проверка разрешений, звонков, Bluetooth, навигации, музыки, расхода батареи и работы в фоне на устройстве. Установка и первичное тестирование только на стоянке.

## Статус
Это спецификация целевой полной версии, не подтверждение реализации или готового APK. Доступность системных функций зависит от версии Android, ролей, разрешений и поддержки сторонних приложений.
